## Summary
This project predicts `yield_tons_per_ha` for smallholder farms in Ethiopia using environmental and survey data.

## Setup & Run
1. Place raw data in `team_6/data/raw/`
2. Install requirements: `pip install -r requirements.txt`
3. Run notebooks in order:
   - `01_cleaning_and_integration.ipynb`
   - `02_analysis_report.ipynb`
   - `03_visualizations.ipynb`
   - `04_modeling_and_evaluation.ipynb`
4. Run Streamlit App: `cd app && streamlit run app.py`
